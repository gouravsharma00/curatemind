Week 1: Introduction to Data in Python

Welcome to your first Python lesson! At the heart of every program is data. Python provides several ways to store, organize, and process data gracefully. Today we'll cover the three foundational concepts: Variables, Lists, and Dictionaries.

1. Variables

Think of variables as named containers. You can place data inside a variable to hold it for later use. Python is dynamically typed, which means you don't have to declare what kind of data the container holds beforehand.

2. Lists

A List is used to store multiple items in a single variable. Lists are created using square brackets `[]` and are ordered, meaning the items have a defined sequence.

3. Dictionaries

Dictionaries store data in key-value pairs using curly braces `{}`. They are incredibly useful for structured data where you want to associate an identifier (key) with a piece of information (value).

app.py 
# Dictionary of student marks
student_marks = {
    "Alice": 95,
    "Bob": 82,
    "Charlie": 88
}

# Processing the dictionary
for student, mark in student_marks.items():
    print(f"{student} scored {mark} points.")
